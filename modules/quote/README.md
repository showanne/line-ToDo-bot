# 💬 Quote Module README

這個模組是本專案的佳句紀錄核心，主要用於在 LINE 對話中快速保存、瀏覽、修改與刪除「佳句」內容。

它支援以下資料欄位：

- `content`：佳句內容
- `source`：出處
- `speaker`：誰說的
- `tags`：標籤（可多個）

---

## 1. 模組定位

`quote` 模組提供：

- 佳句新增
- 佳句編輯
- 佳句刪除
- 佳句列表展示
- 標籤分類管理
- Flex Message 卡片互動
- 對外 REST API 查詢與操作

這個模組屬於對話式資料記錄功能，目標是讓使用者在 LINE 中就能以自然語句的方式保存自己的名言、句子或精簡摘錄。

---

## 2. 核心功能

### 2.1 新增佳句

支援兩種新增方式：

1. 對話式逐步輸入
   - 輸入 `新增佳句`
   - 系統依序問你輸入：內容、出處、誰說的、標籤

2. 一行速記格式
   - 範例：

```text
佳句 + 人生如逆旅，我亦是行人 + 《論語》 + 孔子 + #人生 #哲學
```

其中欄位解析順序如下：

- `內容`
- `出處`
- `誰說的`
- `#標籤`

---

### 2.2 編輯佳句

支援以下兩種做法：

- 快速編輯：`編輯佳句 5`
- Postback 編輯按鈕：從列表卡片直接點選「編輯」

編輯流程會逐步收集：

- 新的佳句內容
- 新的出處
- 新的誰說的
- 新的標籤

若不想修改標籤，可輸入 `無`。

---

### 2.3 刪除佳句

支援以下兩種做法：

- 快速刪除：`刪除佳句 5`
- Postback 刪除按鈕：從卡片底部點選「刪除」

---

### 2.4 列出佳句

使用者可輸入：

```text
列出佳句
list
quotes
佳句列表
```

系統會回傳目前使用者的佳句清單，並以 Flex 卡片形式呈現。

---

### 2.5 查詢筆數

可輸入：

```text
佳句數量
count
quote count
```

系統會回傳目前已記錄的筆數。

---

### 2.6 說明卡

輸入：

```text
help
幫助
說明
指令
```

會回傳 Quote 模組專屬的 Help Flex 卡片，內容包含：

- 新增方式
- 一行速記格式
- 列表與維護指令

---

## 3. Flex 卡片設計

目前 Quote 模組已包含兩種主要 Flex 顯示：

### 3.1 新增成功卡

顯示內容：

- 新增完成時的確認卡
- 顯示佳句內容
- 顯示出處
- 顯示誰說的
- 顯示標籤
- 可直接編輯或刪除

### 3.2 清單卡

顯示內容：

- 使用者的佳句列表
- 每張卡都包含：內容、出處、誰說的、標籤
- 底部有導覽與操作按鈕

### 3.3 Help 卡

顯示 Quote 模組的使用說明與操作範例，讓新使用者可以直接在 LINE 中完成自我導覽。

## 4. 資料模型

主要資料表如下：

- `quotes`
  - `id`
  - `user_id`
  - `content`
  - `source`
  - `speaker`
  - `created_at`

- `quote_tags`
  - `id`
  - `user_id`
  - `name`

- `quote_tag_map`
  - 多對多關聯表
  - 用於將佳句與標籤連結起來

## 5. API 介面

### 5.1 取得使用者佳句

```http
GET /api/quotes?user_id=<user_id>
```

回傳格式：

```json
{
  "status": "success",
  "items": [
    {
      "id": 1,
      "content": "人生如逆旅，我亦是行人",
      "source": "《論語》",
      "speaker": "孔子",
      "tags": ["人生", "哲學"],
      "created_at": "2026-08-04T12:34:56"
    }
  ]
}
```

### 5.2 新增佳句

```http
POST /api/quotes/add
```

Request Body：

```json
{
  "user_id": "default_user",
  "content": "人生如逆旅，我亦是行人",
  "source": "《論語》",
  "speaker": "孔子",
  "tags": ["人生", "哲學"]
}
```

### 5.3 編輯佳句

```http
POST /api/quotes/edit
```

Request Body：

```json
{
  "user_id": "default_user",
  "id": 1,
  "content": "新的佳句內容",
  "source": "新出處",
  "speaker": "新說者",
  "tags": ["新標籤"]
}
```

### 5.4 刪除佳句

```http
POST /api/quotes/delete
```

Request Body：

```json
{
  "user_id": "default_user",
  "id": 1
}
```

## 6. 使用情境

這個模組適合用於：

- 儲存名言佳句
- 記錄講座或經典語錄
- 建立個人的句子分類標籤
- 後續透過 API 介接前端看板或其他模組

---

## 7. 設計重點

- 以 LINE 對話為核心操作入口
- 支援結構化欄位（內容 / 出處 / 誰說的 / 標籤）
- 以 Flex Message 提升可視化體驗
- 保留 REST API 供資料互動與導覽
- 與專案其他模組保持一致的模組化設計
